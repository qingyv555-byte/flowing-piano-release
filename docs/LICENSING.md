## 对外分发时必须做什么

- 保留适用的原版权、许可和无担保声明，并随软件提供完整 GPLv3。
- 修改版显著说明做过修改及相关日期；受 GPL 覆盖的整体衍生程序继续按 GPLv3 提供，不能把它改成禁止再分发或禁止商用的闭源许可。

- 本项目的互联网发行方式：同一个 Release 附上精确版本的完整源码包、构建说明和程序包，源码可按第 6(d) 条免费获取。不要假定 GitHub 自动源码 ZIP 已包括被忽略的资源、子模块或所有必要依赖。

提供源码不等于必须把修改提交回本仓库，也不一概要求向全世界发布；接收者依法拥有继续修改与再分发的权利。

必须保留版权、许可等法律声明；建议在 README 或“关于/开源许可”同时写明：
