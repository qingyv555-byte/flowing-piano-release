# 发布检查单

质量等级以 [CONSTRAINTS](../CONSTRAINTS.md) 为唯一依据。合并 main、RC 或构建安装包必须完成 Level 4，不能用局部检查代替。

- 固定候选提交 SHA、版本号与改动列表；全套测试、Portable 构建/冒烟、Setup 安装/启动/卸载及其他发布检查通过。
- 完成真实声卡、原生文件选择器、高 DPI、保存重开与导出演示；未验证内容明确记录。
- 检查成品携带 LICENSE、COPYRIGHT、第三方声明，以及实际分发的音源、图标、Python、Qt 和传递依赖许可；核对依赖的源码/重链接等适用义务。不以一张依赖名称表代替完整声明。
- 依 [许可说明](LICENSING.md) 准备与程序匹配的完整对应源码、构建/安装说明及必要资源。用全新目录检查材料完整性，不能仅链接不断变化的 main。
- Release 同时上传程序与对应源码包，写明版本、提交 SHA、SHA-256、变化及已知限制。测试版本明确标为预发布。
- 发布后核对下载、哈希、声明和源码入口；旧安装包不视为自动包含新修复或本轮许可材料。

本清单不是验收已通过的记录。每次发行另保存候选 SHA、检查命令、结果及人工验收证据。
