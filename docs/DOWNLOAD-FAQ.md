# Download FAQ / 下载常见问题

**Which Windows package should I choose? / 安装包还是便携版？**

Setup is the standard install-and-uninstall workflow. Portable runs from an
extracted folder. Extract the entire archive before opening the executable.
Setup 适合常规安装与卸载；Portable 解压完整文件夹即可运行，不要只取出其中的 EXE。

**Do I need Python or an API key? / 需要 Python 或 API Key 吗？**

Packaged versions do not require Python. Playing, editing, saving, MIDI import
and MIDI/WAV export do not require an AI key. Optional AI features require a
supported provider configuration and may have provider-side charges.
打包版本不需要 Python；基础音乐功能不需要 AI Key。AI 功能按所配置服务的能力和计费规则工作。

**Does the latest code mean a new download is available? / 源码更新等于新版已发布吗？**

Downloadable builds are attached to a release with their own notes and
checksums. Development and preparation branches may be newer than that build.
下载版本以对应 Release 的说明与校验值为准，开发分支可能领先于已发布安装包。

**Can I keep editing after export? / 导出后还能继续编辑吗？**

Save the project as well as the exported audio or MIDI. WAV is rendered audio;
the project preserves the editor state for continued work.
请同时保存工程。WAV 是音频成品，工程文件用于继续编辑。

**What do the music demos show? / 演示里的音乐从哪里来？**

Playback demonstrations use explicitly identified example or imported projects.
They do not demonstrate live AI composition unless the recording includes that
process. 歌曲播放展示不等于模型现场创作；曲目与来源应随演示注明。

**How do I report a problem? / 如何反馈问题？**

Include the release/version, Windows version, steps to reproduce, and a small
project if you can share it. Remove private material and credentials before
posting. Use [Issues](https://github.com/qingyv555-byte/flowing-piano-release/issues).
