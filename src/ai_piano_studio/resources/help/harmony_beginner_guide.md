## 和弦是什么

三个或更多音组合在一起，可以形成和弦。

例如：

- 哆、咪、嗦一起出现：稳定、明亮。
- 拉、哆、咪一起出现：柔和、略带忧郁。

音乐可以简单分成四层：

- **旋律**：最像人在唱、最容易记住的部分。
- **和弦**：在旋律背后托住情绪。
- **低音**：给音乐稳定的地基。
- **节奏**：决定音乐是平稳、流动、轻快还是有力量。

和弦不是“音越多越好”，而是让几个音共同表达一种情绪。

## 先看懂 C、Am、F

字母和钢琴唱名：

| 字母 | 唱名 |
|---|---|
| C | 哆 |
| D | 来 |
| E | 咪 |
| F | 发 |
| G | 嗦 |
| A | 拉 |
| B | 西 |

### C 大和弦（C）

组成音：**C + E + G = 哆 + 咪 + 嗦**

感觉：明亮、稳定、像“回到家”。

### A 小和弦（Am）

组成音：**A + C + E = 拉 + 哆 + 咪**

字母后面的 `m` 表示“小和弦”。

感觉：柔和、安静、略带忧郁。

### F 大和弦（F）

组成音：**F + A + C = 发 + 拉 + 哆**

感觉：温暖、开阔、有向前发展的感觉。

### G 大和弦（G）

组成音：**G + B + D = 嗦 + 西 + 来**

感觉：有推动力，像一句话还没有说完，常接回 C 大和弦。

因此，新手界面不要只显示 `C / Am / F`，而应显示：

- **C 大和弦（C）｜哆-咪-嗦**
- **A 小和弦（Am）｜拉-哆-咪**
- **F 大和弦（F）｜发-拉-哆**

## 大和弦与小和弦

最简单的理解：

- **大和弦**通常更明亮、稳定、开阔。
- **小和弦**通常更柔和、忧郁、神秘。

这不是绝对规则。速度、力度、音区和节奏也会改变情绪。

## 什么时候加和弦

对新手最简单的做法：

> 每一小节，或者每两拍，选择一个和弦。

适合换和弦的位置：

- 新小节开始
- 旋律出现长音
- 旋律停顿
- 一句话结束
- 情绪准备变化
- 高潮开始前

不要给每一个旋律音都换一次和弦，否则容易杂乱。

## 怎样判断哪个和弦适合

最简单的规则：

> 看旋律中重要的音，是否也包含在和弦里。

例如旋律的重要音是“咪（E）”，可能适合：

- C 大和弦：哆-咪-嗦
- A 小和弦：拉-哆-咪
- E 小和弦：咪-嗦-西

软件会重点观察：

- 强拍上的音
- 持续较长的音
- 小节开头和结尾的音
- 重复出现的音
- 前后和弦是否连接自然

推荐和弦不是唯一答案，可以逐个试听。

## 加低音

只有旋律时，音乐容易显得薄。

旋律在高音区弹“哆4、咪4、嗦4”时，下面加入一个较低的“哆2”，音乐会立刻更稳定。

推荐音区：

- 低音：C2～C3
- 和弦：C3～C4
- 旋律：C4～C6

## 和弦可以怎么弹

### 柱式和弦

三个音同时按下，例如：**哆 + 咪 + 嗦**

特点：稳定、直接、有力量。

### 分解和弦

把和弦拆开弹：**哆 → 咪 → 嗦 → 咪**

特点：流动、柔和，更像钢琴伴奏。

### 低音加和弦

先弹低音，再弹上方和弦。

特点：层次清楚，很适合新手。

### 琶音

和弦音连续向上或向下流动。

特点：梦幻、流畅，适合情绪配乐。

## 和弦转位

C 大和弦的音是“哆、咪、嗦”，也可以排列成：

- 咪、嗦、高音哆
- 嗦、高音哆、高音咪

它们仍然是 C 大和弦。

转位可以减少大跳，让前后和弦连接更顺。新手不需要手动计算，软件可以自动选择移动较少的排列。

## 留白与节奏

音乐不是音越多越好。

可以尝试：

- 乐句之间停半拍
- 结尾保留长音
- 某一小节只放低音
- 高潮前减少音符
- 和弦不要每拍都弹

“短、短、长、停顿”通常比连续相同短音更像一句有呼吸的话。

## 力度音区与层次

### 力度

- 第 1 拍稍强
- 第 2 拍稍轻
- 高潮逐渐加强
- 结尾逐渐减弱

### 音区

伴奏不要和旋律挤在同一位置。旋律在 C4～C6 时，和弦通常放在 C2～C4。

### 层次

可以把音乐想成三个人：

- 高音唱旋律
- 中音补和弦
- 低音提供地基

## 设计高潮

高潮不等于突然塞很多音。

可以逐步增加：

- 旋律升高
- 力度增强
- 单音变成完整和弦
- 低音加入八度
- 分解和弦变密
- 和弦变化稍快

简单结构：

1. 开头：旋律 + 少量低音
2. 发展：加入分解和弦
3. 高潮：完整和弦 + 更强力度 + 更高旋律
4. 结尾：减少音符，留下长音

## 结尾使用终止感

在 C 大调里，最常见的结束方式是：

**G 大和弦 → C 大和弦**

- G：嗦-西-来
- C：哆-咪-嗦

G 像“还没结束”，C 像“终于回到家”。

柔和一点可以用：

**F 大和弦 → C 大和弦**

想让结尾更完整：

- 最后一个和弦时间更长
- 力度逐渐减弱
- 留下低音和旋律主音
- 不要突然切断声音

## 常见问题

### 和弦到底什么时候出现？

“预览”会跟着你刚弹下或刚录下的旋律更新。判断调性时，软件也会参考工程里已经存在的旋律；但实时预览通常只显示当前最后活跃小节的建议。

“自动添加”会等一个小节播放或录制完成，再决定是否写入和弦。这样不会在你还没弹完一句时抢先下结论。

例如，你正在录一小节旋律。录制还在这一小节里时，看到“正在听这一小节”是正常的。播放头走完整个小节后，自动添加才会安全处理它。

### 为什么打开旧工程没有马上铺满和弦？

旧工程里的旋律没有被忽略。它们会参与调性判断。

但实时预览不是“打开工程就重写整首歌”。它通常只看当前最后活跃的小节，所以不会马上给旧旋律铺满和弦，也不会改动你原来的音符。

如果想处理整首歌，请使用“检测整首并生成”。

### 实时预览和“检测整首并生成”有什么区别？

实时预览跟着当前输入工作，通常显示最后活跃小节。自动模式还会等待小节播放或录制完成，才尝试写入。

“检测整首并生成”会立即扫描所有有旋律的小节，并在安全的位置直接加入可靠的和弦。它不会切换实时模式：原来是“预览”就仍是“预览”，原来是“自动添加”就仍是“自动添加”。

例如，旧工程前面已有几段旋律、你现在正在修改结尾时，可以用实时预览听结尾，也可以单独点一次“检测整首并生成”处理整首歌。两者不会互相改模式。

### 为什么这次没有添加和弦？

“没有添加和弦”是一次安全判断，不是工作丢失。你的旋律仍然保留。

常见原因有：

- 旋律音符太少，还看不出稳定方向。
- 调性不清楚，几个方向都像。
- 当前旋律与候选和弦的匹配较弱。
- 目标小节已经有自动生成的和弦。
- 目标小节有你改过、已脱离自动管理（detached）的和弦。
- 你自己的音符与准备加入的和弦位置重叠；软件会优先保护它们。

遇到这些情况，软件宁可不加，也不会硬塞一个不可靠的和弦或覆盖你的内容。

### 为什么已有和弦/重叠音会被跳过？

软件会保护已经存在的内容：自动生成过的和弦、你改过的和弦，以及你手工加入的和声都不会被整首检测覆盖。

这里的“重叠音”专指你手工叠加的和声或叠音，与准备加入的和弦占用了同一段时间和音区；普通的单声部旋律音符不是这种重叠。遇到受保护的位置时，软件会跳过该小节，保留你的原作。

### 怎样更容易得到可靠建议？

先让旋律表达得更完整：

- 多弹几个拍子，不要只留下一个很短的音。
- 让旋律多次回到一个清楚的“回家音”，或在句尾停在它上面。
- 检查是否有不小心叠在同一时间位置的重复音符。
- 使用自动添加时，让播放或录制完整走完当前小节。

例如，一句旋律反复回到“哆”，通常比几个互不相关的短音更容易判断。整理掉意外重叠后，再试听建议或重新检测整首。

### 为什么推荐多个和弦？

同一段旋律可能有不同情绪解释，逐个试听即可。

### 为什么有些旋律音不在和弦里？

短暂的不协调音可以是经过音或装饰音，只要随后回到稳定音，仍可能很好听。

### 为什么自动和弦太满？

可以降低力度、改用分解和弦、减少换和弦次数，或者只保留低音。

### 自动添加后还能修改吗？

可以。自动添加的和弦进入工程后，应当像普通音符一样移动、删除、调整长度与力度。

### 完全看不懂字母怎么办？

先记住四个：

- C 大和弦：哆-咪-嗦
- A 小和弦：拉-哆-咪
- F 大和弦：发-拉-哆
- G 大和弦：嗦-西-来

先学会试听和感受，不需要一次记住所有名称。
